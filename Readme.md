# Пиксель хантер

Игра «Пиксель хантер». Автор — Сергей Иншаков. Интенсив [«Продвинутый JavaScript»](https://htmlacademy.ru/intensive/ecmascript) от HTML Academy.

## Эта ветка

`mvp-serverless` продолжает линию `mvp-server-rewrite` (бывшая `juice`, от коммита `0c551a2`): игровой цикл MVP января–февраля 2019 и сборка на Node 24.

Учебного сервера нет. Вопросы и картинки локальные, статистика партий хранится в браузере.

## Архитектура

`Application` переключает экраны. Игровой цикл живёт в `GamePresenter` ([js/screen/game-screen.js](js/screen/game-screen.js)), состояние — в `GameModel` ([js/data/game-model.js](js/data/game-model.js)), разметка — во `view/`.

Перед новой партией презентер снимает свои прошлые подписки на ответ и перезапуск. Иначе одна партия сохранялась бы дважды и дублировалась в истории.

## Данные

Вопросы — локальный массив в [js/data/questions.js](js/data/questions.js): 10 уровней в формате бывшего API, картинки из `img/paint/` и `img/photo/`. Эти каталоги копируются в сборку вместе с остальными файлами `img/`.

Статистика партий хранится в `localStorage` по имени игрока (ключ `pixel-hunter:<имя>`). Чтение и запись — в [js/actions.js](js/actions.js). Внешних серверов нет.

Если запись статистики не удалась, показывается экран ошибки.

Адаптер в [js/image-loader/image-loader.js](js/image-loader/image-loader.js) подставляет файл и растягивает его на рамку уровня: `468×458` для двух картинок, `705×455` для одной широкой, `304×455` для трёх. `Resizer` отключён: масштаб по одной стороне оставлял пустые поля, и рамка выделения со статистикой ответов не совпадали с картинкой.

`data/paintings.json` и `data/photos.json` удалены: это были списки внешних URL, приложение их не читало.

## Отличие от `master`

На `master` шаблоны лежат в `js/template-modules/`, вопросы — в локальном `js/game-data.js`, плюс юнит-тесты module 4. Этих коммитов в данной ветке нет: игровой цикл написан заново. Вопросы и статистика тоже локальные. Картинки уровней те же, ресайзер к ним не применяется.

## Запуск

```
npm install
npm start
```

`npm start` выполняет `gulp serve`. Сборка — в [gulpfile.mjs](gulpfile.mjs). Рабочая версия Node — 24 (в `package.json` поле `engines.node` — `>=22`).

Зависимости сборки:

- Gulp `^5.0.1`
- Babel 7 (`@babel/core` `^7.28.5`, `@babel/preset-env` `^7.28.5`)
- Webpack `^5.102.1` и `webpack-stream` `^7.0.0`
- ESLint `^8.57.1`
